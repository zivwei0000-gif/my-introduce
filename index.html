擂台背後的蛻變手札

金屬齒輪與軟體邏輯交織出的成長軌跡

PHASE 01 // 啟蒙 • 國小 WRO & IEYI 的初次試煉

「程式與硬體結下的魔法不解之緣」

國小第一次代表參加 WRO 國際奧林匹克機器人大賽與 IEYI 世界青少年創客發明展時，面對複雜的樂高積木機構與感測器觸發失誤，曾感到迷惘。但正是那段在實驗室摸索的時光，點燃了我對自動控制的熱情。

PHASE 02 // 淬鍊 • 經國創客中心與衛冕兩連霸

「衛冕光環下的絕對冷靜」

來到經國國中創客中心後，挑戰升級為多軸人形機器人格鬥與 AI 任務判斷。在 114 年度資通訊大賽尋求二連霸時，面臨著現場燈光干擾與對手特別設計的打法壓力。我和團隊學會屏息專注於微調控制器，將不安轉化為極致的運算精準度。

PHASE 03 // 遠景 • 亞東科大表演賽與未來

「將解決問題的勇氣融入血液」

獲邀至亞東科技大學進行示範表演賽時，看著大專先進們的讚許，我深刻明白：獎牌只是紀錄，真正寶貴的是創客精神——面對未知的程式 Bug 或突發硬體故障時，冷靜拆解問題並永不退縮。
